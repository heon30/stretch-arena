# 쭉! 아레나 · Web Edition v4

귀여운 2D 캐릭터가 길어지는 팔로 싸우는 아케이드 격투게임입니다.

**게임:** https://heon30.github.io/stretch-arena/

## 모드와 조작

- 1인: 컴퓨터와 대전. ← → 또는 A D 이동 / Space 점프 / Z 또는 F 공격.
- 같은 컴퓨터 2인: 1P는 A D 이동 / **G 점프 / H 공격**. 2P는 ← → 이동 / **, 점프 / . 공격**.
- 멀티: 같은 Wi-Fi 태블릿 두 대가 PC 서버를 통해 방 코드로 연결됩니다.
- 60초 제한, 2선승제. 시간 종료 시 남은 체력 비율을 비교합니다.
- 세 맵: 햇살 버섯숲, 노을빛 유적, 달빛 버섯계곡. 아래에서 발판을 통과하고 위로 착지합니다.

## 밸런스 재조정

지형이 포함된 실제 게임 엔진으로 세 맵 × 여섯 상성 × 400경기 = **7,200경기**를 별도 시드로 검증했습니다. 진영을 번갈아 배치하고 세 가지 거리 선호를 가진 봇을 사용했습니다. 무승부는 0.5승입니다. 공격력·회수 시간과 발판 높이를 조정했습니다.

| 캐릭터 | 체력 | 공격력 | 사거리 | 회수 시간 | 전체 평균 승률 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 모찌 | 138 | 13.5 | 250 | 0.37초 | 54.5% |
| 루키 | 81 | 16 | 315 | 0.29초 | 47.7% |
| 루미 | 69 | 16 | 425 | 0.46초 | 46.0% |
| 젤리 | 88 | 16 | 335 | 0.28초 | 51.8% |

결과는 봇 기반 초기 검증입니다. 사람의 전략이나 숙련도까지 보장하지 않으며 상성 차이는 남아 있습니다. 상세 맵별 결과와 조정 전 수치는 `balance-report.json`에서 확인할 수 있습니다.

## 같은 Wi-Fi 멀티 실행

1. 이 저장소의 Code → Download ZIP으로 받고 모두 압축 해제합니다.
2. Windows에서는 `태블릿-대전-시작.cmd`를 실행합니다. Node.js 22 이상 또는 이 PC의 Codex 번들 Node.js를 사용합니다. 다른 운영체제는 `node arena-server.cjs`로 실행합니다.
3. 서버 창에 표시된 태블릿 주소를 같은 Wi-Fi의 두 태블릿 브라우저에서 엽니다.
4. 멀티 선택 → 각자 캐릭터 선택 → 방 만들기 / 코드 입장 → 둘 다 준비 완료.
5. 서버는 대전 중 켜두세요. Windows 방화벽 알림은 개인 네트워크 접근을 허용해야 합니다.

GitHub Pages는 게임 화면만 제공하므로 그 주소에서 WebSocket 서버를 실행하지 않습니다. 사이트의 멀티 탭에 PC 서버 주소를 입력하면 해당 서버 화면으로 이동합니다. 방 코드는 해당 PC 서버에만 존재합니다.

서버 60Hz 판정, 30Hz 상태 전달, 화면 보간, 짧은 이동 예측, RTT 표시, 입력 만료와 최대 30초 재접속을 지원합니다. 실제 Wi-Fi 및 태블릿의 성능에 따라 지연이 달라집니다. 서버 재시작 시 방은 초기화됩니다.

## 개발·검증

외부 npm 패키지가 필요하지 않습니다. Node.js 22 이상:

```sh
npm start
npm test
node tools/validate-balance.cjs
```

`index.html`은 오프라인 실행 가능한 게임 원본입니다. 서버도 이 파일의 전투 엔진을 읽습니다. `src/engine.cjs`는 테스트와 시뮬레이션용 동일 엔진 사본이며 테스트가 일치 여부를 검사합니다. 게임을 수정할 때 두 엔진을 함께 갱신하세요.

클라우드 Node 호스팅에서는 `PORT` 환경변수를 지원합니다. 기본 포트는 8123입니다. 클라우드 호스팅은 별도 설정이 필요하며 이 배포에서는 활성화하지 않았습니다.
