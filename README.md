# 쭉! 아레나 · Online Edition v5

귀여운 2D 캐릭터가 길어지는 팔로 싸우는 아케이드 격투게임입니다.

**게임:** https://heon30.github.io/stretch-arena/

## 모드와 조작

- 1인: 컴퓨터와 대전. ← → 또는 A D 이동 / X 점프 / Z 공격.
- 같은 컴퓨터 2인: 1P는 A D 이동 / **H 점프 / G 공격**. 2P는 ← → 이동 / **. 점프 / , 공격**.
- 멀티: 서로 다른 네트워크의 두 기기가 온라인 서버에 방 코드로 연결됩니다. PC 서버 실행은 필요하지 않습니다.
- 60초 제한, 2선승제. 시간 종료 시 남은 체력 비율을 비교합니다.
- 세 맵: 햇살 버섯숲, 노을빛 유적, 달빛 버섯계곡. 아래에서 발판을 통과하고 위로 착지합니다.

## 밸런스 재조정

지형이 포함된 실제 게임 엔진으로 세 맵 × 여섯 상성 × 400경기 = **7,200경기**를 별도 시드로 검증했습니다. 진영을 번갈아 배치하고 세 가지 거리 선호를 가진 봇을 사용했습니다. 무승부는 0.5승입니다. 공격력·회수 시간과 발판 높이를 조정했습니다.

| 캐릭터 | 체력 | 공격력 | 사거리 | 회수 시간 | 전체 평균 승률 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 모찌 | 138 | 13.5 | 250 | 0.37초 | 54.5% |
| 루키 | 81 | 16 | 315 | 0.29초 | 47.7% |
| 루미 | 69 | 16 | 425 | 0.46초 | 46.0% |
| 젤리 | 88 | 16 | 335 | 0.28초 | 51.8% |

결과는 봇 기반 초기 검증입니다. 사람의 전략이나 숙련도까지 보장하지 않으며 상성 차이는 남아 있습니다. 상세 맵별 결과와 조정 전 수치는 `balance-report.json`에서 확인할 수 있습니다.

## 온라인 멀티

1. 두 기기에서 https://heon30.github.io/stretch-arena/ 에 접속합니다.
2. 멀티 모드에서 각자 캐릭터를 선택합니다.
3. 한 명이 방을 만들고 6자리 코드를 상대에게 알려줍니다.
4. 상대가 코드로 입장하고 두 명 모두 준비 완료를 누르면 시작됩니다.

같은 Wi-Fi나 PC 서버가 필요하지 않습니다. 태블릿·휴대폰은 화면 하단 터치 버튼을 사용합니다. 한 대의 컴퓨터에서 2인 모드를 사용할 때의 H/G 및 ./, 키도 그대로입니다.

온라인 서버: https://stretch-arena-online.onrender.com (Render free / Singapore)

무료 서버는 일정 시간 사용하지 않으면 쉬었다가 다시 시작하므로 첫 방 연결에 약 1분 걸릴 수 있습니다. 준비 중 상태를 표시하고 자동으로 기다립니다. 서버 재시작·새 배포 시 방은 초기화됩니다.

서버 60Hz 판정, 30Hz 상태 전달, 화면 보간, 짧은 이동 예측, RTT 표시, 입력 만료와 최대 30초 재접속을 지원합니다. 네트워크 거리 및 혼잡도에 따라 지연이 달라집니다.

## 개발·검증

외부 npm 패키지가 필요하지 않습니다. Node.js 22 이상:

```sh
npm start
npm test
node tools/validate-balance.cjs
```

`index.html`은 오프라인 실행 가능한 게임 원본입니다. 서버도 이 파일의 전투 엔진을 읽습니다. `src/engine.cjs`는 테스트와 시뮬레이션용 동일 엔진 사본이며 테스트가 일치 여부를 검사합니다. 게임을 수정할 때 두 엔진을 함께 갱신하세요.

클라우드 Node 호스팅에서는 `PORT` 환경변수를 지원합니다. 기본 포트는 8123입니다. GitHub main 변경 시 Render 서버와 GitHub Pages가 자동으로 배포됩니다.
